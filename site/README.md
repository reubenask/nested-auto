# Nested Auto Limited frontend

Static, dependency-free prototype of the premium vehicle-parts explorer.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included interactions

- Layered technical vehicle illustration with inventory-driven part overlays
- Click, arrow-key, drag, and swipe category navigation
- Dynamic part details and zero-stock state
- Step-by-step vehicle selector and multi-vehicle garage
- Compatible-parts inventory view and cart feedback
- Responsive desktop, tablet, and mobile layouts

The implementation is plain HTML, CSS, and JavaScript, so it can be opened directly or integrated into a framework later.
